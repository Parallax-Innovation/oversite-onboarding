# Module 1.1: What is OverSite?

## The Problem

Construction projects are chaotic:
- 80% of projects run over schedule (McKinsey)
- 14+ hours lost per worker per week to miscommunication (FMI/Autodesk)
- Site managers juggle 50+ contractors, schedules, and issues

The bottleneck? **On-site oversight.** The data exists in spreadsheets, project management tools, and email chains - but it's not where the worker is.

## How It Works (User Perspective)

```
MORNING WALKTHROUGH
────────────────────

Site Manager: *walks onto site wearing glasses*
              "Start walkthrough"

OverSite:     "Good morning. I can see the site. What are we
              checking today?"

Site Manager: *looks at exposed wiring*
              "Flag this - exposed wiring in unit 204"

OverSite:     "Issue flagged. Photo captured. I'm notifying
              the electrical contractor now."

              [Behind the scenes: Creates ticket in MS Planner,
               texts contractor, logs to dashboard]

Site Manager: "Who's the HVAC contractor for this building?"

OverSite:     "That's Johnson HVAC. Contact is Mike at 555-1234.
              They're scheduled to finish ductwork by Friday."

Site Manager: "End walkthrough"

OverSite:     "Walkthrough complete. 3 issues flagged. I've
              generated your daily report and sent action
              items to the relevant contractors."
```

## The Key Insight

> "If you could take someone off the street and make them productive
> on day one, that changes the math on every bid we put out."
> — General Contractor, Colorado

OverSite makes **information accessible at the point of work**. The glasses see what you see. The AI knows your project data. Actions happen automatically.

## Tech Stack Summary

| Component | Technology | Purpose |
|-----------|------------|---------|
| Glasses | Meta Ray-Ban | Camera + mic input |
| Mobile App | iOS (Swift) | Connects glasses to cloud |
| Perception AI | Gemini Live | Real-time voice + vision |
| Agent | Claude + E2B | Background task execution |
| Dashboard | Next.js | Observability for managers |
| Database | Supabase | Events, sessions, project data |
| Hosting | Vercel | Web deployment |
