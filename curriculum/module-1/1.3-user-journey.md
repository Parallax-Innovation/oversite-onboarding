## Key Insight: User Never Waits

The magic is in the **local-first + async fan-out** pattern:

1. **Instant feedback** (200ms) - User hears confirmation immediately
2. **Dashboard updates** (~500ms) - Team sees the flagged issue
3. **Background work** (5+ seconds) - Agent creates tickets, sends notifications

The user is already walking to the next issue while the Agent works.
