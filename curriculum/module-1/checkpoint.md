## Creative Thinking

These questions have no single right answer. Think deeply.

4. **Design Challenge:**
   If you were building OverSite for a different industry (healthcare, warehouse, security), what would be the equivalent of "flag this"? What local action would need to happen instantly vs. what could be delegated to the background agent?

5. **Architecture Critique:**
   Why do you think OverSite uses Gemini for real-time perception instead of Claude? What are the tradeoffs? When might you want to swap them?

6. **Edge Case Exploration:**
   What happens if the user flags 50 issues in rapid succession? Trace the flow through all 4 layers. Where might bottlenecks occur?

7. **Future Thinking:**
   The current system injects contractor data into the system prompt. What breaks when a project has 500 contractors instead of 5? How would you redesign it?
