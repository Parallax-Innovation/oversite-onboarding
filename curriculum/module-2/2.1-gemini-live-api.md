# Module 2.1: Gemini Live API

## What is Gemini Live?

Gemini Live is Google's real-time multimodal AI API. It's different from standard chat APIs:

```
┌─────────────────────────────────────────────────────────────────┐
│           STANDARD API vs GEMINI LIVE                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  STANDARD CHAT API                    GEMINI LIVE               │
│  ─────────────────                    ───────────               │
│                                                                 │
│  Request ──────► Response             ◄────────────────────►    │
│  (one-shot)                           (persistent WebSocket)    │
│                                                                 │
│  Text only                            Audio + Video + Text      │
│                                                                 │
│  ~500ms latency                       ~100ms streaming          │
│                                                                 │
│  Stateless                            Session state maintained  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## The Model

OverSite uses:
```
gemini-2.5-flash-native-audio-preview-12-2025
```

This is a special model optimized for:
- Native audio input/output (not text-to-speech conversion)
- Low latency streaming
- Multimodal understanding (sees + hears simultaneously)

## Connection Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                    GEMINI LIVE CONNECTION                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  iOS App                                     Gemini Live API    │
│  ────────                                    ───────────────    │
│                                                                 │
│  ┌─────────────────┐                    ┌─────────────────┐    │
│  │ GeminiLive      │                    │                 │    │
│  │ Service.swift   │◄═══WebSocket══════►│  Gemini Live    │    │
│  │                 │    (persistent)    │  Server         │    │
│  └────────┬────────┘                    └─────────────────┘    │
│           │                                                     │
│           │                                                     │
│  ┌────────┴────────┐                                           │
│  │ Sends:          │                                           │
│  │ • Audio chunks  │ ──► PCM 16kHz mono                        │
│  │ • Video frames  │ ──► JPEG at 1 FPS                         │
│  │ • Text messages │ ──► System prompt, tool results           │
│  │                 │                                           │
│  │ Receives:       │                                           │
│  │ • Audio chunks  │ ◄── AI speech response                    │
│  │ • Transcriptions│ ◄── User + AI text                        │
│  │ • Tool calls    │ ◄── When AI decides to act                │
│  └─────────────────┘                                           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## Message Types

### Outgoing (iOS → Gemini)

```swift
// 1. Setup message (start of session)
{
  "setup": {
    "model": "gemini-2.5-flash-native-audio-preview-12-2025",
    "systemInstruction": "You are OverSite...",
    "tools": [
      { "name": "flag_issue", "description": "...", "parameters": {...} },
      { "name": "execute", "description": "...", "parameters": {...} }
    ]
  }
}

// 2. Audio chunk (continuous)
{
  "realtimeInput": {
    "mediaChunks": [{
      "mimeType": "audio/pcm",
      "data": "<base64 PCM data>"
    }]
  }
}

// 3. Video frame (1 FPS)
{
  "realtimeInput": {
    "mediaChunks": [{
      "mimeType": "image/jpeg",
      "data": "<base64 JPEG data>"
    }]
  }
}

// 4. Tool result
{
  "toolResponse": {
    "functionResponses": [{
      "id": "call_123",
      "response": { "success": true, "message": "Issue flagged" }
    }]
  }
}
```

### Incoming (Gemini → iOS)

```swift
// 1. Audio response
{
  "serverContent": {
    "modelTurn": {
      "parts": [{
        "inlineData": {
          "mimeType": "audio/pcm",
          "data": "<base64 PCM data>"
        }
      }]
    }
  }
}

// 2. Transcription (user or AI)
{
  "serverContent": {
    "inputTranscription": "Flag this exposed wiring"
  }
}
// or
{
  "serverContent": {
    "outputTranscription": "I've flagged the issue"
  }
}

// 3. Tool call
{
  "toolCall": {
    "functionCalls": [{
      "id": "call_123",
      "name": "flag_issue",
      "args": {
        "description": "exposed wiring",
        "location": "unit 204"
      }
    }]
  }
}
```

## Code Walkthrough: GeminiLiveService

```swift
// Simplified from GeminiLiveService.swift

class GeminiLiveService {
    private var webSocket: URLSessionWebSocketTask?

    // Callbacks
    var onAudioReceived: ((Data) -> Void)?
    var onToolCall: ((ToolCall) -> Void)?
    var onInputTranscription: ((String) -> Void)?
    var onOutputTranscription: ((String) -> Void)?

    func connect(config: GeminiConfig) {
        let url = URL(string: "wss://generativelanguage.googleapis.com/...")!
        webSocket = URLSession.shared.webSocketTask(with: url)
        webSocket?.resume()

        // Send setup message
        sendSetup(config)

        // Start receiving
        receiveMessage()
    }

    func sendAudio(_ data: Data) {
        let message = createAudioMessage(data)
        webSocket?.send(.string(message)) { _ in }
    }

    func sendVideo(_ jpeg: Data) {
        let message = createVideoMessage(jpeg)
        webSocket?.send(.string(message)) { _ in }
    }

    func sendToolResult(_ result: ToolResult, callId: String) {
        let message = createToolResultMessage(result, callId)
        webSocket?.send(.string(message)) { _ in }
    }

    private func receiveMessage() {
        webSocket?.receive { [weak self] result in
            switch result {
            case .success(.string(let text)):
                self?.handleMessage(text)
            default:
                break
            }
            self?.receiveMessage() // Continue listening
        }
    }

    private func handleMessage(_ text: String) {
        // Parse JSON and dispatch to appropriate callback
        if let toolCall = parseToolCall(text) {
            onToolCall?(toolCall)
        } else if let audio = parseAudio(text) {
            onAudioReceived?(audio)
        }
        // ... etc
    }
}
```

## Configuration

```swift
// GeminiConfig.swift

struct GeminiConfig {
    static let apiKey = "..."  // From environment
    static let model = "models/gemini-2.5-flash-native-audio-preview-12-2025"

    // Video settings
    static let frameRate: Double = 1.0  // 1 frame per second
    static let jpegQuality: CGFloat = 0.3  // Low quality = smaller payload

    // Audio settings
    static let sampleRate: Int = 16000  // 16kHz
    static let channels: Int = 1  // Mono
}
```
